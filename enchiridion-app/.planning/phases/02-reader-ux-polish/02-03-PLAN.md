  <action>
    STEP 1 — Convert BlockRenderer to StatefulWidget.

    Change `class BlockRenderer extends StatelessWidget` to `class BlockRenderer extends StatefulWidget`. Add two new optional callbacks to the constructor:
      `final void Function(Map<String, GlobalKey> sectionKeys, Map<String, GlobalKey> subsectionKeys)? onKeysReady;`
      `final void Function(Map<String, double> offsets)? onOffsetsReady;`

    Create `class _BlockRendererState extends State<BlockRenderer>`. Move the build logic (settings watch, DefaultTextStyle.merge, _ChapterView) into `_BlockRendererState.build()`. Add these fields to _BlockRendererState:
      `final Map<String, GlobalKey> _sectionKeys = {};`
      `final Map<String, GlobalKey> _subsectionKeys = {};`

    Implement `_buildKeys()`:
    - Clear both maps.
    - Iterate `widget.chapter.sections`: for each section, add `_sectionKeys[section.id] = GlobalKey()`.
    - For each subsection within that section, add `_subsectionKeys[subsection.id] = GlobalKey()`.
    - After populating, call `widget.onKeysReady?.call(_sectionKeys, _subsectionKeys)`.

    Call `_buildKeys()` at the end of `initState()`, then schedule `_calculateOffsets()` via `WidgetsBinding.instance.addPostFrameCallback((_) => _calculateOffsets())`.

    Implement `didUpdateWidget(BlockRenderer old)`: if `old.chapter.id != widget.chapter.id`, call `_buildKeys()` and schedule `_calculateOffsets()`.

    Implement `_calculateOffsets()`:
    - Build `Map<String, double> offsets = {}`.
    - For each entry in `_sectionKeys` and `_subsectionKeys`: get `key.currentContext`, cast findRenderObject() to RenderBox, call `box.localToGlobal(Offset.zero).dy`. Store as `offsets[id] = dy`.
    - Call `widget.onOffsetsReady?.call(offsets)`.

    STEP 2 — Pass keys to _SectionHeader and _SubsectionHeader.

    Add an optional `Key? anchorKey` parameter to `_SectionHeader`. In `_SectionHeader.build()`, wrap the existing Padding widget with `KeyedSubtree(key: anchorKey, child: ...)` when anchorKey is non-null, or pass the key directly to the Padding widget as its `key:` parameter.

    Add an optional `Key? anchorKey` parameter to `_SubsectionHeader`. Apply the same key-forwarding pattern.

    STEP 3 — Wire keys in _ChapterView.build().

    `_ChapterView` currently receives chapter, bookId, fontSize, lineHeight. Add two new parameters:
      `final Map<String, GlobalKey> sectionKeys;`
      `final Map<String, GlobalKey> subsectionKeys;`

    In `_ChapterView.build()`, when adding `_SectionHeader`, pass `anchorKey: sectionKeys[section.id]`. When adding `_SubsectionHeader`, pass `anchorKey: subsectionKeys[subsection.id]`.

    In `_BlockRendererState.build()`, pass `sectionKeys: _sectionKeys` and `subsectionKeys: _subsectionKeys` to `_ChapterView`.

    IMPORTANT: Do not call `_buildKeys()` or create any `GlobalKey()` inside `build()` — keys are created only in `initState()` and `_buildKeys()`.
  </action>
