<objective>
Rename the Surgical Instrumentation topic currently displayed as "Sutures" so it reads
"Suture Material" on every surface a user sees, without touching any identifier, file path, or
medical prose.

Purpose: "Suture Material" is the name the author's master catalog
(`scripts/content/surgical instrumentation.md`) uses for this topic, and it is the clinically precise
term — "Sutures" reads as the technique rather than the consumable.

Output: a one-field title change in the topic catalog, three display-field changes in the content
asset, and a test that pins the rename and proves nothing structural moved.
</objective>
