<objective>
Group the Medical Instrumentation resource list under category section headers, replicating the grouping the Calculators screen already does.

What "these" refers to: `scripts/content/medical_instrumentation.md` is the only resource source file in the repo that is already written as 9 named category headings with bullets beneath them (`scripts/content/surgical instrumentation.md` is one flat bullet run with no headings, and OSCE has its own screen). The batch also walks the Library categories in screen order — dqz (Calculators), dr0/dr1/dr2 (Surgical Instrumentation), dr3/dr4 (Medical Instrumentation), dr5/dr6 (OSCE) — which puts this item and dr4 on the same screen. So "these" is the Medical Instrumentation topic list, and its groups are the 9 headings the author already wrote.

Today `ResourceTopicListScreen` renders one flat run of rows for whatever list it is handed. This plan adds an optional `group` to `ResourceTopic`, a `groupTopicsForDisplay` helper that mirrors `groupByCategory` in `calculator_definition.dart`, a shared `SectionHeader` widget carrying the Calculators header style, and the group assignment for the whole Medical Instrumentation catalog.

Purpose: Medical Instrumentation reads as a browsable, categorised catalog instead of one undifferentiated scroll — the same shape the user already likes on the Calculators screen.
Output: a grouped Medical Instrumentation screen, an unchanged Surgical Instrumentation screen, and two test files pinning both.
</objective>
